## 下次要做的实验（按顺序，成本从低到高）

### 1. 小任务 + 插电（先排除供电）

```bash
# ��着充电线
python -m memobird_printer image tools/calibration/small96.png --ble <地址>
```

- **打出来了** → 是**供电**或**任务大小**问题，进第 2、3 步
- **还是动一下就停** → 打印头/固件问题，进第 4 步

### 2. 不插电打同一张小图（做对照）

如果插电成功、不插电失败 ⇒ **电池撑不住加热电流**，这机器只能插电用。

### 3. 中等任务 + 限速（验证缓冲）

```bash
python -m memobird_printer image tools/calibration/cal60.png --ble <地址>
```

`cal60.png` = 384×480（23 帧 / 23KB）。如果小图能打、这张不能 ⇒ **发送速度超过固件缓冲**。
修法：把 `BlePrinter.send_frames` 的 `inter_frame` 从 0.05 提到 0.15~0.3，或每 8 帧停一下。

### 4. 若以上都失败：查打印头

- 用手指/酒精棉擦打印头（断电）—— 有没有明显划痕/脏污
- 打印时把耳朵贴近，正常应该有"滋滋"的加热声；若完全无声，是加热回路问题
- 热敏纸**光滑面**必须朝打印头（装反就是全白）
