## 2. 加固：360 壳（静态分析的墙）

```
application android:name = com.stub.StubApp        ← 360 的壳入口
assets/libjiagu.so / libjiagu_a64.so / libjiagu_x64.so / libjiagu_x86.so
assets/.jgapp = "16c23737da864d44"                 ← 壳的 app id
classes.dex 里只有 "libjgdtc.so" 一处壳痕迹：
    //data/data/cn.memobird.XGWangYi/lib/libjgdtc.so
```

`classes.dex` 是**整体加密**的，不是普通的"抽取壳"：

| 证据 | 数值 | 含义 |
|---|---|---|
| 文件大小 | 10,447,796 B | 头 112 字节合法（`dex\n035`、file_size、endian 都对） |
| `string_ids_size` | **926** | 只有壳自己的字符串表 → 真代码不在这里 |
| `cn/memobird/**` 类名 | **0** 处 | 业务类一个都不在明文 dex 里 |
| 熵[64KB, 1MB) | **8.000** | 密文（正常 dex 约 5.5–6.3） |

dex 里能搜到的只有第三方库（kotlin、ijkplayer、opencv、pdfium、腾讯/微博/友盟/Bugly/Mob），
所以任何 dex 级静态反编译（jadx/apktool）拿到的都只是 `com.stub.StubApp` 几十行壳代码。

→ 要拿 App 的私有接口/密钥，只能**运行时脱壳**（真机/模拟器 + frida-dexdump 之类）
或**抓包**；本仓库给了抓包脚本 `tools/mitm_capture.py`。

## 3. 能从 APK 静态拿到的有用信息

### 3.1 打印图像流水线是原生实现

`lib/arm64-v8a/libBmpJniUtilDither.so` 导出的 JNI 符号（Java 侧类名
`cn.memobird.app.imageStudio.BitmapJniUtil`）：

```
doDither                     ← 抖动（本库用 Floyd/Atkinson 复刻这条思路）
createRawMonochromeData      ← 生成单色位图
convertArgbToGrayscale / convertGray / convertInk / convertNegative
convertRelief / convertSketch / convertSingle / convertStrokeByArr
wordEnhance / ImageEnhance   ← 文字增强、对比度
getAppSecret                 ← ★ 接口签名密钥藏在 native 层
getXKWID                     ← 某种设备/账号标识
```

`.so` 的只读数据段里还有两个"看起来像密钥"的常量串（一个 16 字符、一个 32 字符），
位置/长度符合编译期常量特征，很可能就是 `getAppSecret()` 的返回值。
**具体值不在此公开**（那是厂商的凭据，公开属于泄露）；本库也用不到它 —— 公开开放平台
和局域网接口都不需要签名，BLE 通道更是完全无鉴权。

> 复现方式：`tools/dexstrings.py <libBmpJniUtilDither.so>` 一跑就能看到，自己做就行。

### 3.2 打印相关的组件（说明设备形态）

```
ui.device.WifiConfigActivity / WifiConfigConnectDeviceActivity / WifiConfig5gHintActivity
ui.device.DeviceListActivity / G5SEPicUpLoadActivity / G5SEPicListActivity
ui.print.PaperSelectActivity / ImageProcessActivity / PreviewActivity / WarningActivity
ui.print.GraffitiActivity / LandscapeTextActivity / NotebookTextActivity
ui.tagPaper.TagPaperEditorActivity
```

权限：`BLUETOOTH` / `BLUETOOTH_SCAN` / `BLUETOOTH_CONNECT` / `BLUETOOTH_ADVERTISE` /
`ACCESS_FINE_LOCATION` / `CHANGE_WIFI_STATE` / `INTERNET`；`usesCleartextTraffic=true`。

→ 同时存在**蓝牙配网 + WiFi 通道**：蓝牙机型（有道口袋打印机、GT1/GO/G4 这一脉）与
WiFi 机型（G2/T2/G5 等）都覆盖。这就是本库做三后端（BLE / 局域网 / 云端）的原因。

### 3.3 资源里唯一的 memobird 域名

把 `res/`、`assets/`、`resources.arsc` 全扫一遍（`tools/scan_urls.py`），命中：

```
study.memobird.cn        ← 学习内容站，不是打印 API
```

打印 API 基址都在加密 dex 里，静态拿不到。其余 `meta-data` 是第三方 SDK 的
（Mob-AppKey/AppSecret、IFLYTEK_APPKEY、cocos2dcpp 等），与打印无关。

## 5. 实机验证记录（GT1，2026-11-15）

第一次真机连上后的对话记录很有价值，三次修正都来自它：

**连接**：BLE 直连成功，`5 个服务 / 15 个特征值`，`ff00` 服务下的
`ff02`（write + writeWithoutResponse）与 `ff01`（notify）都在。

**打印机回包**（说明帧确实进了固件）：

```
aa 13 00 04 | 0b 02 00 10 00 | 0c 02 00 01 00 | 0e 01 00 00 | 06 01 00 00 | fd
   cmd=0x04  tag0x0B=16(总包数)  tag0x0C=1(包序)  tag0x0E=0  tag0x06=0
```

`tag 0x0B` 等于我们发的帧数 16 → 固件认了这个任务。另有 72 字节的 `cmd=0x0A` 回包，
`tag 0x0F` 是 32 字节 ASCII 数字（设备序列号）。

**三个坑（都已修）**：

| 现象 | 根因 | 修法 |
|---|---|---|
| 打校准图却打出 `nice to meet you`（固件自带示范页） | BMP 用 `biHeight` **负值**（top-down 规范写法）；且调色板顺序/像素极性与官方相反 | 改为官方的"非标准 BMP"：`biHeight` 取正 + 数据行序 top-down + **调色板 index0=黑/1=白**（行数据逐字节取反），现在与 PIL 输出**逐字节一致** |
| 字号滑块无效 | 文本帧没发 `tag 0x10`（字号档位）；`0x0D` 加粗、`0x11` 下划线也缺 | 文本帧补齐三个样式 tag，字号按档位映射（≤26→0 / ≤36→1 / 更大→2） |
| 长文本末尾出现奇怪符号（像表情） | 文本整段塞进一帧，超过固件单包文本上限，解析错位 | 按官方 SDK 的 **300 字节/包**分包 |

**附带修正**：图像帧不再发 `tag 0x0A`（官方 SDK 不发）；图案打完补一帧纯换行走纸。

> 教训：`biHeight` 正负、调色板黑白色序、像素极性 —— 这三样任意一个错，
> 固件的反应都是"当成无效内容"，而不是报错。所以对照一个**已被实机验证过**的
> 实现（`memobird-gt1-mcp`）比自己推规范快得多。

## 6. 为什么最后没有硬啃脱壳

* 真机脱壳需要：Android 设备/模拟器 + root + frida-server（360 壳有反调试）。
  当前机器没有连设备，也没装模拟器 —— 这是唯一的外部阻塞项。
* 而这些信息**已经有更省事的等价来源**：咕咕机的蓝牙帧格式有完整的公开抓包分析
  （GT1，360 独角兽训练营）、局域网接口有可用的 HACS 集成实测报文、云端接口有官方
  《WebAPI》PDF v0.5。三条路径都能在本库中落地，且**都已经用真实报文对齐过**（见
  `docs/协议说明.md`）。
* 如果后续确实要 App 的私有接口（例如它自己的 ak/私钥/私有路由），最省事的顺序是：
  1. 抓包（`tools/mitm_capture.py`，10 分钟，若 App 无证书固定即可直接拿到）；
  2. 装一个 Android 模拟器 + `frida-dexdump` 脱壳（30–60 分钟）；
  3. 找 **2.2.0 / 2.3.0 / 2.4.0** 这些**未加固**的旧版 APK 直接反编译（最省事，
     但国内镜像站当前从本机不可达，需要你本地有梯子或镜像）。
