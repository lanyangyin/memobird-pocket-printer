# 部署文档（手机端）

> 适用范围：**已经装好 Termux + proot-distro + Ubuntu，且能 `proot-distro login ubuntu` 进系统**。
> 本文从"拿到代码"开始，一步一步写到"稳定后台运行、能打印"。
> 装 Termux / Ubuntu 的步骤不再重复。
>
> 相关文档：原理与协议见 [`协议说明.md`](协议说明.md)，为什么用 Web Bluetooth 见
> [`手机端WebBluetooth.md`](手机端WebBluetooth.md)。

---

## 0. 五分钟版（熟手直接照抄）

```bash
# ① 进 Ubuntu
proot-distro login ubuntu

# ② 拿代码（把 <你的仓库> 换成实际地址；也可以直接用电脑推过来的 zip）
cd ~ && git clone <你的仓库> memobird-pocket-printer && cd memobird-pocket-printer

# ③ 依赖
apt update && apt install -y python3 python3-pil fonts-noto-cjk

# ④ 自检（全 OK 再往下）
python3 phone/doctor.py

# ⑤ 起服务
bash phone/start.sh            # 后台常驻，日志 server.log

# ⑥ 手机 Chrome 打开
#    http://127.0.0.1:8000
```

剩下的内容是把上面每一步**为什么这么做、出错怎么办**讲清楚。

## 1. 部署前自检：`phone/doctor.py`

别急着起服务，先跑这一个是**性价比最高的一步** —— 它能提前把 90% 的部署问题揪出来：

```bash
cd ~/memobird-pocket-printer
python3 phone/doctor.py            # 默认检查 8000 端口
python3 phone/doctor.py --port 8080
```

正常输出（每项含义见下表）：

```
==============================================================
 memobird 手机端部署自检
==============================================================
 [OK  ] Python 版本    3.11.9
 [OK  ] Pillow       10.2.0
 [OK  ] Pillow 绘制    中文文本可渲染
 [OK  ] 中文字体        /usr/share/fonts/opentype/noto/NotoSansCJK-Regular.ttc
 [OK  ] 目录完整性       5 个关键文件齐全
 [OK  ] 端口 8000      空闲
 [OK  ] 回环监听         127.0.0.1:41233 可绑可连
 [OK  ] 编码冒烟         文本 1 帧 / 位图 3 帧（384×47）
--------------------------------------------------------------
 通过。下一步：
   python3 phone/serve.py --port 8000
   手机 Chrome 打开 http://127.0.0.1:8000
```

| 检查项 | FAIL 时的含义与修法 |
|---|---|
| Python 版本 | 低于 3.8 → `apt install -y python3`，或用 `python3.11` 显式调用 |
| Pillow | 没装 → `apt install -y python3-pil`；apt 装不上就 `pip3 install pillow` |
| Pillow 绘制 | 库损坏或架构不匹配 → 重装 Pillow |
| 中文字体（WARN） | 中文会打成方块 → `apt install -y fonts-noto-cjk` |
| 目录完整性 | 解压不全 / 在错误目录 → 重解压，确认 `web/index.html` 在 |
| 端口占用（WARN） | 上次没退干净 → `bash phone/stop.sh`，或换个端口 |
| 回环监听 | 极少见，proot 网络异常 → 重启 Termux |
| 编码冒烟 | 代码有问题 → 把报错原文发出来 |

> 提醒项（WARN）不影响启动，但**中文字体那条一定要修**，否则打印出来全是 □。

## 2. 获取代码

四种方式，按你网络情况选一种。

### 2.1 直接 clone（手机能上 GitHub 时）

```bash
cd ~
git clone https://github.com/<你>/memobird-pocket-printer.git
cd memobird-pocket-printer
```

> 国内网络注意：`github.com` 的网页/TLS 可能被掐（表现为 clone 卡住或 `GnuTLS recv error`）。
> 可以换镜像前缀：
> ```bash
> git clone https://ghfast.top/https://github.com/<你>/memobird-pocket-printer.git
> ```

### 2.2 用最小包（推荐，只有 ~45 KB）

电脑上：

```powershell
cd <项目目录>
python tools/make_phone_zip.py          # 生成 memobird_phone.zip
python -m http.server 9000              # 临时 HTTP 服务
```

手机浏览器打开 `http://<电脑IP>:9000/memobird_phone.zip` 下载，然后在 Ubuntu 里：

```bash
mkdir -p ~/memobird-pocket-printer && cd ~/memobird-pocket-printer
apt install -y unzip        # 极简镜像里可能没有
# zip 放在 /sdcard/Download/ 里，proot 里可直接读（Termux 已授权存储时）
unzip /sdcard/Download/memobird_phone.zip
```

### 2.3 adb push

```powershell
adb push <项目目录> /sdcard/
```

```bash
cp -r /sdcard/<项目目录名> ~/memobird-pocket-printer
```

### 2.4 从 Termux 主系统复制进 proot

```bash
# 在 Termux（不是 Ubuntu）里
termux-setup-storage
cp -r ~/storage/downloads/memobird_phone.zip ~/
proot-distro login ubuntu -- bash -lc 'cd ~ && unzip -o ~/memobird_phone.zip'
```

> 装完确认三件东西在：`memobird_printer/`、`web/`、`phone/`。少一个就重来。

## 3. 安装依赖

### 3.1 必需（一个包就够）

```bash
apt update
apt install -y python3 python3-pil
```

`python3` 已存在时 apt 会跳过；`python3-pil` 提供 Pillow。

### 3.2 强烈建议（中文字体）

```bash
apt install -y fonts-noto-cjk
```

没有 CJK 字体时文字会渲染成方块。`doctor.py` 的「中文字体」那行会 WARN。

### 3.3 apt 源慢 / 装不上时的备选

```bash
# 换清华源（Ubuntu 24.04 示例，其余版本改代号）
sed -i 's@//.*archive.ubuntu.com@//mirrors.tuna.tsinghua.edu.cn@g' /etc/apt/sources.list
apt update

# 或者用 pip 装 Pillow（需要能访问 pypi 或国内源）
pip3 install pillow -i https://pypi.tuna.tsinghua.edu.cn/simple
```

### 3.4 不需要装的东西（重要，别浪费时间）

| 不需要 | 原因 |
|---|---|
| `bleak` / `pybluez` / BlueZ | 蓝牙由 **Chrome** 做，Python 完全没碰蓝牙 |
| `flask` / `fastapi` | 服务只用标准库 `http.server`，零额外依赖 |
| root / `tsu` / Magisk | 全流程不需要提权 |
| `termux-api` | 只有想装 Termux:Boot 自启时才涉及，且不是必须 |

验证：

```bash
python3 -c "import PIL, sys; print(sys.version.split()[0], PIL.__version__)"
```

## 4. 启动服务

### 4.1 前台启动（第一次调试用这个，方便看日志）

```bash
cd ~/memobird-pocket-printer
python3 phone/serve.py
```

```
memobird phone server 1.1.0
  打开： http://127.0.0.1:8000
  注意：Web Bluetooth 只在 **安全上下文** 下可用，
        所以务必用 127.0.0.1/localhost 打开（不要用局域网 IP）。
  停止： Ctrl-C
```

### 4.2 后台常驻（日常用这个）

```bash
bash phone/start.sh          # 写 server.pid，日志追加到 server.log
bash phone/stop.sh           # 停止
tail -f server.log           # 看日志
```

`start.sh` 会做三件事：查 `python3` 在不在、检测是否已在运行（避免双开）、启动失败时自动打日志尾部。

### 4.3 参数

| 参数 | 默认 | 说明 |
|---|---|---|
| `--port` | `8000` | 换端口用；端口被占时 `doctor.py` 会提醒 |
| `--host` | `127.0.0.1` | **保持默认**。改成 `0.0.0.0` 只能用局域网 IP 访问，而那不是安全上下文，Web Bluetooth 会直接不存在 |

环境变量方式也行：`PORT=8080 bash phone/start.sh`。

### 4.4 为什么必须是 `127.0.0.1`

Chrome 只把 **`https://`** 和 **`http://localhost` / `http://127.0.0.1`** 当作安全上下文。
`navigator.bluetooth` 在非安全上下文里**根本不存在**（不是报错，是 `undefined`）。

> 想从电脑访问手机上这个页面？做不到「又能打印」这件事 —— 电脑那端没有安全上下文。
> 电脑端请直接用 CLI：`python -m memobird_printer text "hi" --spp COM5`（见主 README）。

## 5. 让它一直活着

### 5.1 阻止 Termux 被系统杀

Android 会回收后台进程。在 **Termux（不是 Ubuntu）** 里：

```bash
termux-wake-lock
```

这会挂一个唤醒锁（`termux-wake-lock` 是 Termux 自带命令，不需要额外装）。

### 5.2 手动恢复流程（最简单可靠）

手机重启 / Termux 被杀之后：

```bash
proot-distro login ubuntu                        # ① 进 Ubuntu
cd ~/memobird-pocket-printer && bash phone/start.sh   # ② 起服务
```

### 5.3 开机自启（可选，需要 Termux:Boot）

1. 装 **Termux:Boot**（F-Droid 上的官方插件 App），打开一次让它注册。
2. 创建 `~/.termux/boot/start-memobird.sh`（**Termux 家目录**，不是 Ubuntu 里的）：

```bash
mkdir -p ~/.termux/boot
cat > ~/.termux/boot/start-memobird.sh <<'EOF'
#!/data/data/com.termux/files/usr/bin/sh
termux-wake-lock
proot-distro login ubuntu -- bash -lc 'cd ~/memobird-pocket-printer && bash phone/start.sh'
EOF
chmod +x ~/.termux/boot/start-memobird.sh
```

> proot 里**没有 systemd**，别写 `.service` 文件，不起作用。

### 5.4 日志

```bash
tail -n 50 server.log          # 最近日志
: > server.log                 # 清空
```

正常工作日志很短（只有启动横幅 + 5xx 报错），不会涨得很快。

## 6. 浏览器侧准备

| 项 | 要求 |
|---|---|
| 浏览器 | **Android 版 Chrome**（或 Edge）。Firefox 不支持 Web Bluetooth；微信/QQ 内置浏览器不行 |
| Chrome 版本 | Web Bluetooth 自 Chrome 56 起支持；建议用最新版（`chrome://version` 自查） |
| 权限 - 定位 | Android 11 及以下扫描 BLE **必须**给 Chrome 定位权限 |
| 权限 - 附近设备 | Android 12+ 需要「附近的设备」权限 |
| 屏幕 | 打印期间**保持屏幕常亮、Chrome 在前台**（后台标签页会被限流，BLE 写入会断） |

打开：`http://127.0.0.1:8000`

页面底部会显示 `server 1.1.0 · PIL ok`；如果是 `PIL 缺失`，回第 3 节装 `python3-pil`。
日志区首次打开应出现 `服务就绪，先「连接打印机」再打印`。

## 7. 首次连接与打印

### 7.1 连接

1. **先杀掉有道打印机 App**（同一时间只允许一个 App 占用打印机）。
2. 点右上角 **连接打印机**。
3. Chrome 弹出设备选择框 → 选你的打印机（名字可能是 `GT1-xxxx` / `Memobird-xxxx` / 一串 MAC 类似物）。
4. 连上后顶部变绿：`已连接 xxx · 写 ff02`（`ff02` 是 GT1 系的可写特征值）。

> 弹窗里**看不到任何设备** → 见第 9 节「蓝牙层」。

### 7.2 先打校准图（务必先做这一步）

「调试」页 → **打印校准图**。它会打出一张 384×320 的标记图，用来一次性确认：

```
┌──────────────────────────┐
│ ■  TOP 上                │   ← 左上角必须是实心黑块
│    左上应为黑块           │
│                          │
│ ▬▬                       │   ← 阶梯条：第 1 条最短，第 8 条最长
│ ▬▬▬▬                     │
│ ▬▬▬▬▬▬                   │
│                   row 1  │
│                   …      │
│  ───── 右侧虚线 ─────     │
│                          │
│ BOTTOM 下 / 384 dots     │
│ 1234567890…              │
└──────────────────────────┘
```

对照判定（**按优先级从上往下试，改一个重打一次**）：

| 纸面现象 | 结论 | 操作 |
|---|---|---|
| 方向和预览一致、字清晰 | 格式全对 | 直接开始正常打印 🎉 |
| 上下颠倒 | 行序反了 | 图片页勾 **垂直翻转**，重打 |
| 全白 / 只有极少黑点 | 电量不足 / 纸装反 / 数据被拒 | 先充电、确认热敏面朝打印头；再试浓度 2；GT1 只认 BMP 帧（裸位图已移除） |
| 糊成一团、断行、丢行 | 分片太大 | 调试页「写入分片」改 **20 B**，重打 |
| 只打出第一段就停 | 多帧之间被限流 / 没预热 | 分片改 20 B + 保持「预热包」勾选 |
| 左右镜像 | 列序反了（少见） | 把现象发我，需要加 `hflip` |
| 完全没反应、机器不响 | 帧没进去 | 看日志是否每帧都 `完成 N B`；若卡在某帧，改小分片 |

### 7.3 文字打印

「文字」页签 → 输入 → `预览`（浏览器里看到的就是纸上要出的，384 点宽）→ 打印。

* 默认 **GBK 文本帧**：一行字通常 1 帧、几十字节，**亚秒级**出纸。
* 含 GBK 编不了的字符（emoji、部分生僻字）时，服务端会自动退回图片模式，日志会显示 `format=bmp`。
* 想改字号/抖动：字号滑块 14–48；文字建议 `阈值`（最锐），不要用抖动。

### 7.4 图片打印

「图片」页签 → 选图 → 选抖动 → `预览` → 打印。

| 图片类型 | 推荐二值化 |
|---|---|
| 照片、渐变、灰度图 | `Floyd 抖动`（默认） |
| 线稿、截图、文字图 | `阈值` |
| 想要复古网点感 | `Bayer` |
| 对比度低、发灰 | `Atkinson` |

尺寸会被自动等比缩到 384 宽；很长的图会按高度一路打下去（注意纸量）。

## 8. 参数与性能

### 8.1 数据量换算

| 内容 | 载荷 | 20 B/写 ≈ 写入次数 | 预计耗时 |
|---|---|---|---|
| 一行文字（GBK 帧） | 20–60 B | 1–3 | < 1 s |
| 一段文字（转位图 384×200） | ~9.6 KB | ~480 | 5–10 s |
| 图片 384×320 | ~15 KB | ~770 | 10–20 s |
| 图片 384×800 | ~38 KB | ~1900 | 30–60 s |

### 8.2 想更快

调试页把「写入分片」从 20 调到 64 / 128 / 182（= MTU−3）。**能提速 3–8 倍**，但部分固件会丢包 → 出现断行就退回 20。

### 8.3 想更省纸

* 文字优先用 GBK 帧（不转位图，高度自然紧凑）
* 图片先裁掉大片空白再传
* 预览里看黑点占比，太黑说明阈值/抖动选得不对（费墨也费纸）

## 9. 故障排查（按层定位，别乱试）

### 9.1 服务层：页面打不开

```bash
curl -s http://127.0.0.1:8000/api/health      # 期望 {"ok": true, ...}
bash phone/stop.sh && bash phone/start.sh     # 重启
ss -ltnp 2>/dev/null | grep 8000              # 看端口在不在监听
```

| 现象 | 原因 | 修法 |
|---|---|---|
| 拒绝连接 | 服务没起 | `bash phone/start.sh`，看 `server.log` |
| 服务起了但页面 404 | 不在项目根目录启动 | `cd ~/memobird-pocket-printer` 再起 |
| 页面能开、底部显示 `PIL 缺失` | 缺 Pillow | `apt install -y python3-pil` |
| 页面一片白 | `web/` 没解压全 | 重解压，确认 `web/app.js` 存在 |

### 9.2 编码层：点了打印没反应 / 报 500

页面的日志区会写 `文字打印 失败：HTTP 500: ...`。同时在 Ubuntu 里看服务端堆栈：

```bash
tail -n 30 server.log
```

单独验证编码（绕过浏览器）：

```bash
curl -s -X POST http://127.0.0.1:8000/api/encode \
  -H 'Content-Type: application/json' \
  -d '{"kind":"text","text":"hello","format":"gbk"}'
# 期望：{"frames":["..."],"meta":{"format":"gbk","chunks":1,...}}
```

### 9.3 浏览器层：`navigator.bluetooth` 是 undefined

| 检查 | 做法 |
|---|---|
| 地址栏是不是 `127.0.0.1` | 用局域网 IP 一定不行，换回 `127.0.0.1:8000` |
| 是不是 Chrome | 微信/QQ/UC/夸克内置浏览器不行，用系统 Chrome 打开 |
| Chrome 版本 | `chrome://version` 看是否 ≥ 105 |

### 9.4 蓝牙层：弹窗里没设备 / 连上就断

| 现象 | 原因 | 修法 |
|---|---|---|
| 弹窗里空的 | 定位/附近设备权限没给 | 系统设置 → 应用 → Chrome → 权限 → 允许「位置」或「附近的设备」 |
| 弹窗里空的（权限已给） | 打印机被 App 占着 | 杀掉有道打印机 App，或重启打印机 |
| 连上 1 秒就断开 | 同上，或距离太远 | 关掉官方 App；离近一点 |
| `没找到可写特征值` | 特征值不是 `ff02` | 点 **探测 GATT**，把表格发我（页面会自动把表打到调试页） |
| 能连、写不进去 | 需要 write-with-response | 页面已自动回退；若仍失败，把日志里的报错发我 |

**GATT 表长这样**（正常 GT1 应该是这个形状）：

```
service 0000ff00-0000-1000-8000-00805f9b34fb
   chr 0000ff02-0000-1000-8000-00805f9b34fb  [write,writeWithoutResponse]
   chr 0000ff01-0000-1000-8000-00805f9b34fb  [notify]
service 0000180a-...
   chr 00002a29-...  [read]        ← 厂商名
```

### 9.5 打印机层：有反应但出白纸 / 字迹太浅

| 现象 | 原因 | 修法 |
|---|---|---|
| 出白纸但机器走纸 | 数据格式对、位图全白 | 检查是否勾了「反色」；换「阈值」模式试 |
| 出白纸且不走纸 | 只有预热包进去了 | 分片改 20 B；确认日志里每帧都 `完成` |
| **字迹发浅/发灰** | **① 电量低（最常见）** ② 纸装反 ③ 打印头脏 ④ 浓度没调 | ① 充满电再打 —— 热敏头电压随电量掉，低电量必然发灰；② 热敏面（光滑面）朝打印头；③ 用酒精棉/纸巾擦打印头；④ 页面「浓度」调到 加深/更黑/最黑（会牺牲细笔画的清晰度） |
| 字迹太黑、笔画粘连 | 浓度过高 | 浓度调回「标准」，或二值化换 Floyd |
| 打印发灰且只有半边 | 纸仓压不紧 / 打印头一侧脏 | 重新装纸、擦打印头 |

> 电量怎么看：调试页点「查询状态」，回包里的 1 字节 tag 会同时打印十进制（例如
> `tag=0x1 len=1 17 (23)`）。若那个值明显偏低，先充电再做其它排查。

## 10. 升级 / 重置 / 卸载

```bash
# 升级（git 方式）
cd ~/memobird-pocket-printer
bash phone/stop.sh
git pull
bash phone/start.sh

# 升级（zip 方式）：重新解压覆盖，注意先停服务
# 重置：清掉运行态
bash phone/stop.sh && rm -f server.pid server.log

# 卸载：直接删目录；没有系统级安装痕迹、没有后台服务注册
rm -rf ~/memobird-pocket-printer
```

页面里没有持久化状态（不存账号、不存设置），所以**不需要清理浏览器数据**。

## 11. 安全与隐私

* 服务**只监听 `127.0.0.1`**：同一 WiFi 下的其他设备访问不到。
* 不上传任何内容：图像/文字只在本机内存里变成字节，出网流量为零（`serve.py` 里没有任何外部请求）。
* 不落盘：日志只记状态码，不记打印内容。
* 不用任何 token / ak / 设备绑定：BLE 通道无鉴权，也不碰开放平台。
* 页面是静态文件，没有第三方 JS/CDN 请求。

## 12. 另一种跑法：纯静态页（不开服务端）

如果不想在手机上跑 Python（或者想把页面分享给别人），可以把 `web/` 打成**单文件静态页**，
挂到 GitHub Pages 或任何 https 托管上，手机 Chrome 直接开 URL 就能打印。

### 12.1 构建

```bash
python tools/build_static.py          # → docs/index.html（约 120 KB，gzip 64 KB）
```

产物是自包含的：CSS、encoder.js、render.js、GBK 码表、app.js 全部内联，**没有任何外链**。

### 12.2 启用 Pages（点三下）

仓库 → **Settings** → **Pages** → Source 选 *Deploy from a branch*
→ Branch 选 `main`，目录选 **`/docs`** → **Save**。

等一分钟，访问 `https://<你的用户名>.github.io/<仓库名>/`。

### 12.3 它怎么知道该用哪种模式

页面启动时先探一下 `/api/health`（2.5 秒超时）：

* 通了 → **服务端模式**，编码交给 Python
* 不通 → **浏览器模式**，用 `encoder.js` 本地编码，并自动加载 GBK 码表

页脚会写清楚当前是哪一种：`编码：Python 服务端 v1.1.0` 或 `编码：浏览器本地（纯静态）`。
两种模式下动作、按钮、日志完全一样。

### 12.4 差别在哪

| 项 | 服务端模式（serve.py） | 纯静态模式（Pages） |
|---|---|---|
| 文字渲染 | Pillow + 系统字体 | canvas + 系统字体 |
| 抖动算法 | Python 浮点实现 | `encoder.js`，**与 Python 逐字节等价**（有测试） |
| 文字帧 | GBK（1–4 次写） | GBK（内嵌码表，同样 1–4 次写） |
| 图片缩放 | Pillow LANCZOS（细节更好） | canvas 高质量缩放（够用） |
| 依赖 | `python3-pil` | 无 |
| 离线 | ✅ 完全离线 | ❌ 首次加载要联网（打印内容不外发） |
| 换设备 | 只在本机 127.0.0.1 | 同一 URL 谁都能用 |

### 12.5 怎么选

* **手机上日常用** → 服务端模式（图片质量最好、完全离线）
* **想发给别人 / 多设备用 / 不想装 Termux** → 纯静态模式
* 两者可以**同时存在**：同一份代码，Pages 站点和本地 `serve.py` 互不干扰

> 纯静态模式同样要求安全上下文，所以 **必须 https**（Pages 就是 https）或 localhost。
> 用 `file://` 直接双击打开不行 —— Web Bluetooth 在 `null` origin 上会被拒。

## 附录 A：HTTP API 参考

服务默认 `http://127.0.0.1:8000`。

### `GET /api/health`

```json
{"ok": true, "version": "1.1.0", "pil": true, "protocols": ["ble"], "width": 384}
```

### `POST /api/encode`

请求（文字，走 GBK 帧）：

```json
{"kind": "text", "text": "你好", "fontSize": 26, "mode": "threshold", "format": "gbk"}
```

请求（文字转位图 / 图片）：

```json
{"kind": "image", "dataUrl": "data:image/png;base64,...",
 "mode": "floyd", "format": "bmp", "vflip": false, "invert": false}
```

响应：

```json
{"frames": ["<base64 的整帧>", "..."],
 "meta": {"format": "gbk|bmp|raw", "chunks": 3, "bytes": 2256,
          "preheat": 2048, "width": 384, "height": 47}}
```

`frames` 里的每一条就是**一段可以直接写进 GATT 特征值的完整字节流**（含 `AA` 头与校验和）。

### `POST /api/preview`

同样的请求体，返回 `image/png`：抖动后的实际点阵（页面用它做"所见即所得"）。

### `POST /api/calibration`

```json
{"format": "bmp", "vflip": false}
```

返回与 `/api/encode` 相同结构，内容是校准图。
