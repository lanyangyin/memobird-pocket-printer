# tools/experiments/ — 真机协议实验脚本

这些脚本不是日常要用的工具，而是**为了定死某个字段语义而做的实验**。
每个都写清了判据和当时的结论，方便以后换机型时照着重跑。

前提：电脑有蓝牙适配器、打印机没被别的设备占着。

| 脚本 | 干什么 | 判据 | 实机结论（GT1） |
|---|---|---|---|
| `tag_map.py` | 写 `cmd 0x03 tag/value` → 读状态 → 看哪个字段变了 → 还原 | 变了 = 该 tag 是设置项 | `0x02`、`0x03` 是设置项；`0x01/0x04/0x05/0x06` 写不动 |
| `sleep_test.py` | 把 `0x02` 设成 1，**保持连接**静置 80s 再读 | 读不到 = 已休眠 | 仍然在线 → 不是"连着就计时"的休眠 |
| `autooff_test.py` | 把 `0x02` 设成 1，**主动断开**静置 100s 再扫描 | 扫不到 = 已关机 | 仍然广播 → `0x02` **不是**自动关机时间 |
| `drain_test.py` | 连打全黑/半黑图，打完立刻读 + 冷却观察 | 温度会跳高再回落；电压会掉再回升 | `0x04` 81→80（负载下掉）；`0x01` 纹丝不动 |
| 手测（无脚本） | **抽出热敏纸**再读状态 | 某个字段 0→1 = 缺纸标志 | **`0x06` 0→1（00:24:39）、放回 1→0（00:28:57）**，双向验证；同时状态灯变红 ✅ |
| `charge_watch.py`（在 `tools/` 下） | 每 N 秒独立连接采样一次，输出 CSV | 充电时电量应缓升 | 充电 10 分钟无变化（时间太短） |

## 目前的理解（截至 2026-11-17）

* `0x01 = 23` —— 恒定值，**既不是温度也不是电量**。四组刺激（充电 10 分钟、打满黑页、
  用手捂热电池、写入 30）全部无反应。这台机器电池是三线（黑 GND / 红 V+ / 黄 NTC），
  有热敏电阻但没有电量计芯片，固件也不上报电量。
* `0x04 = 80↔81` —— **电压类读数**：空载 81、打黑页掉到 80，之后自己回来。
* `0x02 = 10` —— 可写设置项（1..60），含义未定；**已排除**"自动关机时间"。
* `0x03` —— 指示灯开关 0/1，可读写，因果已用肉眼验证（关灯/开灯有反应）。
* **`0x06` —— 缺纸标志**：有纸 0、抽出纸 1（同时状态灯变红）✅
* `0x05` / `0x13` —— 只读状态位/标志位，语义仍未明。

## 经验（换机型也适用）

1. **先分清"只读传感器"和"可写设置"**：写一个值再读回状态，变了才是设置项。
2. **别信一次读数**：`0x04` 自己会在 80/81 之间抖，单次"变了"可能是噪声。
3. **慢变量要长时间采样**：电量百分比不会因为你打一页就动，得几十分钟量级。
4. **低电量时别打满黑图**：会把设备直接打到关机，实验白做。
